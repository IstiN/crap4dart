# Note: n_0001_d1d2

crap4dart mutation-gate dogfooding facts (2026-10-11): (1) Dart's List.sort uses sign-based binary insertion sort for small lists — `compare() > 0` vs `<= 0` — so a comparator's `return -1` mutated to `return 0` is a truly EQUIVALENT mutant (unkillable by any test), while `return 1` -> `return 0` IS killable but only when an element triggering that branch sits AFTER an element of the other kind in the input array (insertion probes compare(element, existing)). (2) Interpreting self-CRAP: `dart run bin/crap4dart.dart analyze` without fresh LCOV reports CRAP as if coverage=0 (CC^2+CC) — always generate coverage/lcov.info first; and any method with CC > 8 exceeds the 8.0 threshold even at 100% coverage (CRAP = CC), so high-CC methods must be refactored, not just tested. 0.11.0 shipped with red self-check (Max CRAP 27.67, method _DocsVisitor._enclosingIsPublic at 25% cov) because the release verification skipped the coverage-dependent path.
